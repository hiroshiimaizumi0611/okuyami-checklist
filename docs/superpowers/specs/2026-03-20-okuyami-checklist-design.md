# おくやみ手続き診断サービス Design

- Date: 2026-03-20
- Status: Draft for planning
- Working title: Okuyami Checklist

## 1. Summary

日本の一般消費者向けに、家族が亡くなった後の手続きを整理する Web サービスを提供する。
ユーザーは 10〜15 問の診断に回答し、自分の状況に応じた手続き一覧と優先順位を受け取る。
無料版では要約結果を表示し、有料版では期限順の詳細チェックリスト PDF を提供する。

このサービスの価値は、制度の網羅的解説ではなく、「自分はいま何を先にやればよいか」を短時間で把握できることにある。

## 2. Business Goal

### Primary goal

- 月 30,000 円規模のスモールビジネスを成立させる

### Revenue model

- 無料: 診断 + 要約結果
- 有料: 個別化された詳細チェックリスト PDF
- 初期価格案: 1,480 円

### Success model

- 月 21 件前後の PDF 購入で月 30,000 円を超える
- 初期集客は営業ではなく検索流入を主軸にする

## 3. Target User

### Core user

- 日本在住の一般消費者
- 家族が亡くなった直後から 10 か月以内の手続きが必要な人
- 制度の全体像や優先順位がわからず、何から着手すべきか困っている人

### User characteristics

- 営業や紹介で獲得するのではなく、検索で自力流入する
- 相続・行政・年金・保険の専門知識は持っていない
- 長い解説記事より、自分向けに整理された行動リストを求める

### Typical search intents

- 親が亡くなったら 手続き
- 死亡後 何をする
- 相続放棄 いつまで
- 死亡後 手続き チェックリスト

## 4. Problem Statement

死亡後の手続きは、役所、年金、保険、税、相続など複数領域に分かれており、期限も異なる。
一般ユーザーにとって難しいのは、情報が存在しないことではなく、自分に関係のある手続きが何で、どの順番で確認すべきかが見えないことだ。

既存の一般記事や自治体配布資料は有用だが、次の課題が残る。

- 自分に不要な情報も多く、読む負荷が高い
- 自治体差分と全国共通事項の区別がつきにくい
- 期限が異なる手続きの優先度を整理しづらい
- 法的判断が必要なケースと、一般案内で足りるケースの境界がわかりにくい

## 5. Product Principle

- 一般論に徹し、法的判断はしない
- AI の自由生成より、説明可能なルールベース判定を優先する
- 記事サイトではなく「自分専用の手続き地図」を提供する
- 全国共通の主要手続きを先に扱い、自治体差分は確認導線で逃がす
- 危険ケースは無理に案内せず、専門家または公式窓口への相談を促す

## 6. MVP Scope

### Included

- 集客用ランディングページ
- 10〜15 問の診断フォーム
- ルールベースでの手続き抽出
- 無料の要約結果画面
- 有料の詳細チェックリスト PDF
- 公式情報へのリンク
- 危険ケースの注意表示
- 基本的な計測

### Excluded

- 遺産分割方法の助言
- 相続税額の計算
- 相続放棄や申告の適否判断
- 正式書類の作成代行
- 自治体ごとの差分データの網羅
- 複雑な管理画面
- 専門家マッチングの本格導入

## 7. User Experience

### Flow

1. ユーザーは検索経由でランディングページに来る
2. 「3 分で必要な手続きを整理」と伝えて診断開始を促す
3. 診断で状況を選択式で入力する
4. 無料版の結果画面で、期限順に整理された手続きの要約を見る
5. 詳細版が必要なユーザーは有料 PDF を購入する
6. 複雑ケースのユーザーには、専門家相談または公式窓口確認を強く案内する

### UX goals

- 入力の心理負担が低い
- すぐに結果が返る
- 結果が「自分向け」と感じられる
- 法的に危うい領域では踏み込みすぎない
- 家族と共有しやすいアウトプットを用意する

## 8. Diagnosis Design

### Question design principles

- すべて選択式または簡単な入力にする
- 法律判断を直接ユーザーにさせない
- 手続きの有無や優先度分岐に必要な情報のみ聞く
- 15 問を超えない

### Example question categories

- 亡くなった方との関係
- 住んでいた自治体
- 年金受給の有無
- 健康保険の種類
- 不動産の有無
- 自動車の有無
- 相続人が複数か
- 借金や債務の不安があるか
- 生命保険の有無
- 勤務先や退職状況

### First-pass diagnostic question set

初期実装では、次の質問セットをベースにする。

1. 亡くなった方との関係
2. 亡くなったのはいつか
3. 最後に住んでいた自治体
4. あなた以外の相続人がいるか
5. 不動産があるか
6. 自動車があるか
7. 借金や保証債務の不安があるか
8. 年金を受給していたか
9. 健康保険の種類は何か
10. 生命保険に加入していたか
11. 会社員または公務員として働いていたか
12. 世帯主変更が必要そうか
13. 銀行口座やクレジットカードの整理が必要か
14. 家族間でもめる可能性があるか

### Core procedure categories mapped from diagnosis

- 役所関係
- 年金関係
- 健康保険関係
- 税・相続期限関係
- 名義変更や資産整理関係
- 民間契約の整理関係
- 専門家相談が望ましいケース

### Output categories

- まず 1〜2 週間で確認したいこと
- 3 か月以内に要注意のこと
- 10 か月以内に確認すること
- 複雑なので専門家相談を検討したいこと

## 9. Core Features

### 9.1 Landing Page

- 課題の共感
- 3 分診断の訴求
- 一般案内に徹する姿勢の明示
- 購入前に無料結果を見せる導線

### 9.2 Diagnosis Form

- スマホ中心のシンプルな UI
- 進捗表示
- 中断しにくい短い質問文

### 9.3 Result Summary

- 手続きを期限順に整理して表示
- 各項目に「なぜ表示されたか」を短く示す
- 公式確認先の導線を表示
- 危険ケースでは注意カードを表示

### 9.4 Paid PDF

- 期限順チェックリスト
- 各手続きの準備物
- 確認先の種類
- 家族共有用メモ欄
- 専門家相談推奨フラグ
- 更新日時と免責文言
- 購入直後に画面上でダウンロードでき、あわせて再取得用メール送付も行う

## 10. Content and Data Model

MVP では、AI に本文生成させるのではなく、運用可能な構造化データで管理する。

### questions

- id
- text
- answer_type
- options
- order
- help_text

### procedures

- id
- name
- short_description
- deadline_bucket
- official_link
- caution_text
- national_or_local_flag
- requires_expert_flag
- required_items_hint
- updated_at

### result_rules

- id
- condition_expression
- procedure_id
- priority
- visibility_reason
- escalation_flag

## 11. Decision Logic

判定はルールベースで行う。
診断回答に対して、該当する手続きと注意事項を抽出し、期限順に再整列して結果を返す。

### Rule examples

- 年金受給あり: 年金関係の届出候補を表示
- 不動産あり: 名義変更や専門家相談導線を強める
- 借金の可能性あり: 相続放棄の期限注意を強く表示
- 相続人が多い: 一般案内だけでは不足する可能性を表示

### Design constraints

- 推論過程が追えること
- ルール追加・修正が容易であること
- 複雑ケースのエスカレーションが一貫していること

## 12. Trust, Legal Safety, and Content Policy

このサービスは、手続き整理サービスであり、法律・税務・個別事情についての判断提供サービスではない。

### Required safety measures

- 画面と PDF に一般案内である旨を明示
- 公式情報リンクを併記する
- 更新日時を明記する
- 危険ケースで専門家相談を促す
- 「〜すべき」と断定する文言を避ける

### Escalation triggers

- 相続人が多い
- 不動産がある
- 借金や保証債務の不安がある
- 相続人間で争いの懸念がある
- 制度適用可否の判断が必要

## 13. Monetization

### Free tier

- 診断
- 要約結果
- 上位の重要手続きと期限カテゴリの要約
- 危険ケースの注意表示
- 公式確認先への導線

### Paid tier

- 詳細版 PDF
- 期限順の整理
- 準備物ヒント
- 家族共有向けメモ欄
- 専門家相談フラグ
- 表示された全手続きの詳細一覧
- 各手続きが表示された理由
- 手続きごとの確認先種別
- 再取得しやすい配布導線

### Free vs paid boundary

無料版では、「何を優先すべきか」を判断するための要約に留める。
有料版では、「実際に動くために必要な整理情報」を渡す。

- Free: 期限順のサマリー、優先カテゴリ、危険ケース注意、公式確認導線
- Paid: 全件一覧、準備物ヒント、表示理由、メモ欄、共有しやすい PDF 形式

### Initial pricing

- 採用価格: 1,480 円
- 将来的な価格テスト候補: 980 円, 1,980 円

## 14. Acquisition Strategy

営業を避ける前提のため、初期獲得は検索流入を中心に組み立てる。

### Initial acquisition plan

- 検索意図が強い記事を 5〜10 本作る
- 各記事から無料診断へ誘導する
- 診断完了後に有料 PDF を提案する

### Content themes

- 親が亡くなった直後の手続き
- 期限がある代表手続き
- 相続放棄の期限注意
- 年金・保険・役所まわりの初動

## 15. Architecture

MVP では、更新性と保守性を優先し、構成はできるだけ薄くする。

### Components

- LP / 診断 UI
- 判定ロジック
- コンテンツデータ管理
- 決済
- PDF 生成
- 計測

### Technical direction

- フロントエンドは 1 つの Web アプリで完結させる
- 判定ロジックはサーバー側または共有ライブラリで実装する
- コンテンツは JSON または単純な DB テーブルで管理する
- 初期段階では CMS を作らない
- AI 自由生成は導入しない

## 16. Operations

### Operational requirements

- 各手続きに最終更新日を持つ
- 公式ソース URL を保持する
- 全国共通か自治体差分ありかを記録する
- 注意喚起テンプレートを共通化する
- リンク切れと更新漏れを確認する運用を持つ

### Update policy

- 全国共通の主要手続きから優先更新する
- 自治体差分は個別網羅せず、確認導線を維持する
- 法制度変更時は該当手続きデータを優先更新する

## 17. Metrics

### Business metrics

- 診断開始率
- 診断完了率
- 結果閲覧率
- 購入率
- 購入単価
- 月間売上

### Product metrics

- どの質問で離脱が多いか
- どの手続きカテゴリがよく表示されるか
- 危険ケース比率
- 公式リンククリック率

## 18. Testing Strategy

### Unit tests

- 回答条件に応じて適切な手続きが表示される
- 危険ケースでエスカレーションが出る
- 優先順位の並び替えが正しい

### Integration / E2E tests

- 診断開始から結果表示まで
- 決済から PDF 取得まで
- 無料導線と有料導線の分岐

### Content QA

- リンク切れ検知
- 期限表現の整合
- 注意文言の有無
- 更新日の表示確認

### Safety checklist

- 個別法務判断を断定していないか
- 公式確認導線があるか
- 危険ケースの誘導が抜けていないか

## 19. Release Strategy

### Phase 1

- 全国共通の主要手続きだけで MVP を公開
- SEO 記事から流入を得る
- 診断完了率と購入率を観測する

### Phase 2

- よく見られる手続きカテゴリを深掘りする
- PDF の価値を高める
- 複雑ケースの相談導線を追加検討する

## 20. Planning Constraints

実装計画では次を守ること。

- まずは全国共通の主要手続きだけに絞る
- 判定ロジックを説明可能な形で実装する
- 法務リスクを避けるため、一般案内と専門家誘導の境界を崩さない
- CMS や高度な自治体別対応は後回しにする
- 月 30,000 円達成に必要な最短経路を優先する

## 21. Final Product Definition

最初に作るべきものは、「大きな相続サービス」ではない。
日本の一般消費者向けに、死亡後の手続きを個別診断で整理し、無料の要約結果と有料の詳細チェックリスト PDF を提供する、狭くて実用的な Web サービスである。
